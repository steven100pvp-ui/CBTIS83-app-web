JavaScript: variables e introducción

JavaScript permite mostrar mensajes, pedir datos y calcular.

let nombre = prompt("Tu nombre"); alert("Hola " + nombre); let n1 = Number(prompt("Número 1")); let n2 = Number(prompt("Número 2")); alert(n1 + n2);

prompt devuelve texto. Usa Number() para operaciones matemáticas.
